# 요구사항 정의 및 범위

기준은 사용자에게 전달된 F2001~F2016/NF2001~NF2007 요약과 첨부 `2회차_셀프·상호_체크리스트.pdf`, `.xlsx` 27개 항목입니다. 두 첨부의 본문을 직접 읽고 원본 파일을 `templates/`에 보존했습니다. 별도의 공식 요구사항 정의서 원본과 최초 수업 베이스 코드 원본은 제공받지 못했으므로 이 문서는 전달된 기준을 영화 서비스에 적용한 프로젝트 정의서입니다.

| ID | 정의 및 수락 기준 |
|---|---|
| F2001 | 영화 메타데이터 964건을 각각 한 청크로 색인. 외부 문서 청크 수와 별도 집계. 제목·원제·연도·장르·감독·배우·줄거리 포함 |
| F2002 | 같은 입력 재색인 시 ID와 건수 유지. 변경/누락만 upsert |
| F2003 | P1이 영화·질문 기반 검색어 JSON 반환. 제목·연도 필수 검색어 보강 |
| F2004 | API 후보 검색→P2 채택/탈락→채택 본문만 수집. 같은 질문은 TTL 캐시 재사용. 명시적 snapshot 대안 |
| F2005 | 외부 본문 chunk/overlap 설정 변경과 청크 수 비교. 영화 메타데이터는 분할하지 않음 |
| F2006 | Top-k 변경 시 외부 근거 목록 비교. 메타데이터 1건은 별도 |
| F2007 | LangGraph 사용자 노드는 retrieve와 generate 정확히 두 개 |
| F2008 | [근거 N]와 표시 목록 일치, TMDB/Wikipedia 구분, 관련 근거 없으면 추측 금지 |
| F2009 | movie_id별 대화 분리 |
| F2010 | 영화 속 과학·역사 사실 검증에도 동일 근거·인용 경로 적용 |
| F2011 | 연도·장르·감독 조건 기반 영화 탐색 |
| F2012 | 수집/생성 진행 상태, 키 없음·색인 없음 안내. 일반 영화 도메인으로 건강/금융 면책 항목은 해당없음 |
| F2013 | 별도 HTML/CSS/JS UI 심화: 선택하지 않음 |
| F2014 | MMR 비교 심화: 선택하지 않음 |
| F2015 | 5질문 이상 RAG 유무 비교 심화: 선택하지 않음 |
| F2016 | 출처 종류 구분: 기존 기능 유지, 실제 답변 UI 최종 검증은 미확인 |
| NF2001 | 첫 질문/두 번째 질문 전체 처리 시간을 각각 기록. 임의 합격 시간 기준 없음 |
| NF2002 | 동일 질문 재수집 방지. HTTP/질문 캐시 적용 |
| NF2003/NF2004 | 키를 코드·제출물에 넣지 않음. UI에 프롬프트 전문·상세 오류/추적을 표시하지 않음 |
| NF2005 | 수집·색인·검색·생성·UI 모듈 분리 |
| NF2006 | 식별 가능한 User-Agent, 최소 간격, 직렬 요청, 재시도, Retry-After/maxlag 처리 |
| NF2007 | 데이터 출처·이용조건과 실행 방법을 README에 기록 |

이번 실행은 무료 Wikipedia GET 및 로컬 검증만 수행했습니다. GMS 키 신규 설정, 유료 모델 예산, 계정 변경, 다른 사람 명의 커밋, PR은 범위에 없습니다. 이후 사용자가 NIGHTPURI 명의 커밋과 원본 origin/master push를 명시적으로 승인했습니다. 인증 계정은 검증했지만 저장소 push 권한이 false로 확인되어 로컬 커밋만 남기고 원격 쓰기는 중단합니다. 따라서 전체 실서비스 합격 및 학생 상호 평가를 주장하지 않습니다.
